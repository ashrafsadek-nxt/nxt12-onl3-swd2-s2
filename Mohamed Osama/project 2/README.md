    # E-commerce Scaffold


    This scaffold includes a **frontend** (React + Vite) and **backend** (Node + Express) to get you started quickly.

## Structure

- backend/ - Express API with simple JSON file DB
- frontend/ - React app (Vite)

## Quick start

1. Backend:

```bash
cd backend
npm install
npm run start
```

2. Frontend:

```bash
cd frontend
npm install
npm run dev
```

Frontend expects the backend at `/api/products` on the same host. In development with Vite you can use a proxy or run both and configure CORS.

---

You can modify the files under `/frontend/src/components` and `/backend/data/products.json` to add more products or features.
